# Changelog

## 1.0.0

First public release.

- Hotkey scan of both trade offers with an in-game overlay showing totals, demand and a verdict
- Reads item names with the text recognition built into Windows, no extra installs
- Handles wrapped names, quantity badges, Chroma tags and items that share a name
- Tier values (L, R, U, C) converted with the same ladder as the MM2Values calculator
- Demand, rarity and stability ratings from MM2Values
- Value browser with search, rarity filters and sorting
- Themes, overlay size and opacity, compact mode, adjustable fair-trade range and sound volume
